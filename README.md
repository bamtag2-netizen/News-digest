# الموجز اليومي 📰

تطبيق ويب عربي يجمع الأخبار من خلاصات RSS لأشهر الوسائل الإعلامية ويقدّم ملخصاً يومياً، ويعمل مجاناً على **GitHub Pages** مع تحديث تلقائي عبر **GitHub Actions**.

## المزايا
- جمع تلقائي كل 3 ساعات من 18 مصدراً: الجزيرة، BBC عربي، فرانس 24، سكاي نيوز عربية، العربية، CNN بالعربية، DW، يورونيوز، RT، الشرق الأوسط، Al Jazeera English، BBC World، تلفزيون سوريا، الإخبارية السورية، حلب اليوم، قناة سما، بلدي نيوز، عنب بلدي.
- لكل مصدر عدة روابط احتياطية؛ إن لم تعمل خلاصة الموقع يُجلب عبر Google News تلقائياً.
- **الترجمة**: الأخبار الإنجليزية تُترجم للعربية تلقائياً، مع زر «الترجمة» للتشغيل/الإيقاف، و«عرض الأصل»، و«ترجمة المقال كاملاً».
- تسمية «الكيان المحتل» بدلاً من «إسرائيل» في العناوين والفلاتر (يمكن إيقافها بجعل `rename_israel` = false في `config/taxonomy.json`).
- **ملخص اليوم**: أهم 7 قصص مرتبة حسب عدد المصادر التي تناولتها.
- **البحث** عن موضوع (اكتب أي كلمة) أو **دولة** (30+ دولة) أو مصدر أو فترة زمنية، مع تصنيفات (سياسة، اقتصاد، رياضة…).
- رابط كل خبر ظاهر تحته، والضغط عليه يفتح الخبر في موقع الوسيلة الإعلامية.
- زر **تحديث**: يعيد تحميل التقرير ويحاول جلب آخر الأخبار مباشرة من المصادر.
- **تصدير PDF** (من نافذة الطباعة ← «حفظ بتنسيق PDF»)، والروابط تبقى قابلة للضغط داخل الملف.
- **السلة**: احفظ أي تقرير (بالفلاتر التي اخترتها) مع اسم وملاحظة، وافتحه أو صدّره لاحقاً.
- **الأرشيف التلقائي**: نسخة من تقرير كل يوم لآخر 90 يوماً.
- **الأخبار المفضلة**، مشاركة عبر واتساب، نسخ الرابط، الكلمات الأكثر تداولاً، وضع ليلي، اختصار `/` للبحث.

## التشغيل على GitHub (مرة واحدة)
1. أنشئ مستودعاً جديداً (Public) على GitHub، مثلاً `news-digest`.
2. ارفع كل ملفات هذا المجلد كما هي (مع مجلد `.github`).
3. **Settings ← Actions ← General ← Workflow permissions** ← اختر **Read and write permissions** ← Save.
4. **Settings ← Pages** ← Source: **Deploy from a branch** ← Branch: `main` / `(root)` ← Save.
5. **Actions ← تحديث الأخبار ← Run workflow** لأول جلب.
6. افتح موقعك: `https://<اسم-المستخدم>.github.io/news-digest/`

بعدها يتحدث تلقائياً كل 3 ساعات.

## التخصيص
- **المصادر**: عدّل `config/sources.json` (أضف أي رابط RSS).
- **الدول والتصنيفات وكلماتها**: `config/taxonomy.json`.
- **عدد مرات التحديث**: سطر `cron` في `.github/workflows/update-news.yml`.

## ملخص ذكي (اختياري)
أضف مفتاح Anthropic API في **Settings ← Secrets and variables ← Actions** باسم `ANTHROPIC_API_KEY`، وسيكتب السكربت ملخصاً بالعربية في 6–8 نقاط مع كل تحديث.

## ملاحظات
- إذا ظهر ✗ بجانب مصدر في سجل Actions فرابط RSS الخاص به تغيّر؛ استبدله في `sources.json`.
- التحديث المباشر من المتصفح يمر عبر خدمات CORS عامة مجانية وقد يتعذر أحياناً؛ عندها يُعرض آخر تقرير جمعه GitHub.
- السلة والمفضلة محفوظة في متصفحك على الجهاز نفسه؛ استخدم «تنزيل JSON» للنسخ الاحتياطي.
- ملف `data/news.json` المرفق عينة أولية من أخبار 21 نوفمبر 2026 وسيُستبدل بأول تشغيل.
